# 📖 eBook Creation Guide
## Полное руководство по созданию eBook версии на Amazon KDP

**⏰ Время выполнения:** 2-4 часа  
**💰 Ожидаемый доход:** +$400-600/месяц  
**🎯 Статус:** КРИТИЧНО - СДЕЛАЙТЕ ЭТО ПЕРВЫМ

---

## 🚀 Быстрый старт (5 минут)

Если вы в спешке:

```
1. Кликните: https://kdp.amazon.com/bookshelf
2. Войти с вашим Amazon аккаунтом
3. Нажмите "Create new title" → "Kindle eBook"
4. Загрузите PDF вашей книги
5. Установите цену $9.99
6. Нажмите "Publish"
Готово за 30 мин, доступно через 12-48 часов
```

---

## 📋 Подробное руководство

### **Шаг 1: Подготовка файла (30 мин)**

#### **Что вам нужно:**
- ✅ PDF версия вашей книги
- ✅ Amazon аккаунт с KDP
- ✅ Информация о книге (название, описание, ключевые слова)

#### **Проверка PDF файла:**

```
Требования Amazon:
✓ Формат: PDF, MOBI, EPUB, или RTF
✓ Размер: макс 650 МБ
✓ Разрешение: минимум 150 DPI для изображений
✓ Шрифты: встроены в PDF
✓ Язык: русский (UTF-8)

Рекомендуемые параметры:
• Размер: A5 или Letter (210×280 мм)
• Поля: минимум 0.5 дюйма (12.7 мм)
• Номера страниц: да
• Оглавление: желательно интерактивное
```

**Если у вас есть MOBI:**
- Используйте его - Amazon предпочитает MOBI для Kindle
- Скачайте KindleGen (бесплатно) если нужно конвертировать

**Если только DOC/DOCX:**
- Используйте Calibre (бесплатно): https://calibre-ebook.com
- Word → Save as PDF
- PDF → KindleGen → MOBI

### **Шаг 4: Загрузка файла (5 мин)**

#### **В KDP Bookshelf:**

```
1. Кликнуть "Upload eBook Manuscript"
2. Выбрать ваш PDF/MOBI файл
3. Дождаться загрузки (обычно 30-60 сек)
4. Кликнуть "Save and Continue"

⚠️ Если загрузка сбойит:
- Проверьте размер (макс 650 МБ)
- Используйте другой браузер
- Попробуйте MOBI вместо PDF
```

#### **Amazon проверит файл:**
- Обычно: 1-5 минут
- Если найдет ошибки - покажет список
- Исправьте и загрузите снова

### **Шаг 6: Установка цены (10 мин)**

#### **Ценообразование для eBook:**

```
РЕКОМЕНДУЕМАЯ ЦЕНА: $9.99 USD

Почему именно $9.99?
✓ Психологическая цена (выглядит бюджетнее чем $10.99)
✓ Компромисс между Paperback ($16.99) и мобильностью
✓ Конкурентоспособна на рынке медицинских eBook
✓ Максимум 70% от продаж (vs 35% за $2.99-9.99)
✓ Оптимальная конверсия для этой категории

Потенциальные продажи при разных ценах:
• $4.99 → 250-300 продаж/месяц → $1,250-1,500
• $9.99 → 150-200 продаж/месяц → $1,050-1,400  ⭐ ОПТИМУМ
• $14.99 → 80-100 продаж/месяц → $800-1,000
```

#### **В KDP:**

```
1. Нажать "Kindle eBook Pricing"
2. Выбрать "Individual Territories"
3. Установить:
   • United States: $9.99
   • UK: £7.99
   • Euro: €9.99
   • Russia: ₽790
   • Other: $9.99
4. Выбрать "35% royalty" или "70% royalty"
   → Выберите 70% (доступно при $2.99-9.99)
```

**ВАЖНО: 70% royalty vs 35% royalty**
```
При $9.99:
• 70% royalty: $6.99 за продажу ✅ ВЫБИРАЙТЕ ЭТО
• 35% royalty: $3.50 за продажу

Разница: почти 2x больше дохода!
```

## 📱 Привязка к Paperback версии

### **Amazon связывает автоматически:**

Если у вас уже есть Paperback версия:
- ✅ Того же автора (Sergiy Sushkov)
- ✅ Того же названия
- ✅ Публикация в KDP

Amazon свяжет их в течение 48-72 часов.

### **Как проверить связывание:**

```
1. Перейти на страницу Paperback на Amazon.com
2. Найти раздел "Formats and Editions"
3. Должны быть видны:
   ✓ Paperback ($16.99)
   ✓ Kindle Edition ($9.99)
   ✓ Hardcover (если будет)
```

### **Если связывание не произошло:**

```
1. Подождите 72 часа
2. Проверьте в KDP:
   • Название точно совпадает
   • Автор точно совпадает
   • Язык: Russian
3. Если все еще не связано - напишите в KDP Support
```

## 💡 Советы по оптимизации

### **После опубликования (День 2-3):**

1. **Добавьте в Author Central:**
   - Ссылка на eBook в вашем профиле
   - Опишите eBook в Author Central
   - Это увеличит видимость на +20-30%

2. **Заказайте Proof Copy:**
   - Для проверки качества
   - Себестоимость печати (~$8-10)
   - Можно заказать в KDP

3. **Настройте KDP Select (опционально):**
   - Исключительность в Amazon (90 дней)
   - +$200-400/месяц из Kindle Unlimited
   - Но не сможете продавать на других сайтах

Результат: 40-50% меньше кликов

❌ ОШИБКА #3: Без ключевых слов

❌ ОШИБКА #4: Неправильный язык

❌ ОШИБКА #5: 35% вместо 70% royalty
Неправильно: Выбрать 35%
