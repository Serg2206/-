# 👤 Amazon Author Central Setup Guide
## Полное руководство по созданию профиля автора

**⏰ Время выполнения:** 1-2 часа  
**💰 Влияние:** +20-30% видимость, +15-25% продажи  
**🎯 Приоритет:** ВЫСОКИЙ - делайте после eBook

---

## 🚀 Быстрый старт (10 мин)

```
1. Перейти: https://authorcentral.amazon.com
2. Войти с Amazon аккаунтом (или создать новый)
3. Добавить вашу книгу (Paperback ASIN)
4. Загрузить биографию
5. Загрузить фото
6. Готово!

Результат: Author Page видна на вашей странице + рекомендации Amazon
```

## 📋 Подробное руководство

### **Шаг 1: Регистрация на Author Central (10 мин)**

#### **A. Переход и вход:**

```
1. Открыть: https://authorcentral.amazon.com
2. Нажать "Sign in with your Amazon account"
3. Использовать ваш Amazon KDP аккаунт
4. Если нет аккаунта - нажать "Create new Amazon account"
```

#### **B. Регион (ВАЖНО):**

Author Central отличается для разных регионов:
```
USA:        https://authorcentral.amazon.com (выбирайте ЭТО)
UK:         https://authorcentral.amazon.co.uk
Germany:    https://authorcentral.amazon.de
France:     https://authorcentral.amazon.fr
Spain:      https://authorcentral.amazon.es
India:      https://authorcentral.amazon.in
Japan:      https://authorcentral.amazon.co.jp
```

**Рекомендация:** Используйте USA версию - она дает больше опций.

---

### **Шаг 2: Добавление вашей книги (5 мин)**

#### **Поиск и связывание Paperback:**

```
1. В Author Central нажать "Books" → "Add a new book"
2. Найти вашу книгу:
   • Введите название: "Рациональное использование антибиотиков..."
   • Или введите ASIN (найти в KDP Bookshelf)
3. Нажать на вашу книгу
4. Нажать "Claim"
5. Система проверит авторство
```

#### **Если система просит подтверждение:**

```
Обычно нужно:
✓ Email подтверждение на authorcentral@amazon.com
✓ Может занять 24-48 часов
✓ После подтверждения - полный доступ

Если долго ждете - напишите в поддержку Author Central
```

#### **После связывания вы получите доступ к:**

```
✓ Страница книги на Amazon (можно редактировать)
✓ Рейтинги и отзывы
✓ Информация о продажах (для некоторых регионов)
✓ Отчеты о доходах
```

### **Шаг 4: Загрузка фотографии (5 мин)**

#### **Требования к фото:**

```
Размер:         200×200 пиксели (минимум)
Формат:         JPG, PNG, GIF
Размер файла:   макс 5 МБ
Качество:       хорошо видное лицо, профессиональное
Ориентация:     портрет
Фон:            белый или светлый (не отвлекающий)
```

#### **Рекомендации:**

```
✓ Профессиональное фото (с улыбкой)
✓ Медицинский халат или формальная одежда
✓ Хорошее освещение
✓ Четкое лицо
✓ Без солнечных очков

✗ Селфи
✗ Коллаж или несколько людей
✗ Животные
✗ Чрезмерные фильтры
✗ Логотипы
```

#### **Как загрузить:**

```
1. В Author Central найти "Photo"
2. Нажать "Upload Image"
3. Выбрать файл с вашего компьютера
4. Обрезать/позиционировать (если нужно)
5. Нажать "Save"
```

### **Шаг 6: Свяжите обе версии (eBook + Paperback)**

#### **Автоматическое связывание:**

```
Обычно Amazon связывает автоматически, если:
✓ Одинаковое название
✓ Одинаковый автор
✓ Обе публикации в KDP

Время: 48-72 часа после публикации eBook
```

#### **Ручное связывание (если не произошло):**

```
1. Перейти в Author Central на страницу вашей книги
2. Найти раздел "Editions"
3. Нажать "Link editions"
4. Выбрать версии (Paperback + Kindle)
5. Подтвердить связывание
```
