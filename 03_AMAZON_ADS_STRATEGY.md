### **Шаг 6: Мониторинг и оптимизация (текущее)**

#### **ЧТО ОТСЛЕЖИВАТЬ:**

```
Ежедневно (первая неделя):
☐ Impressions (показов) - должны расти
☐ Clicks (кликов) - должны быть
☐ CTR (Click-through rate) - 0.5-1.5% нормально
☐ Spend (потрачено денег) - должно быть примерно $5/день

Еженедельно:
☐ ACoS (Ad Cost of Sales) - сколько потратили / сколько заработали
☐ Orders (заказы/продажи) - от вашей рекламы
☐ ROAS (Return on Ad Spend) - заработок / затраты
☐ Conversion rate - кликов → продажам
```

#### **ГЛАВНАЯ МЕТРИКА - ACoS (Ad Cost of Sales):**

```
Формула:
ACoS = (Потрачено на рекламу) / (Доход от продаж) × 100%

Пример:
- Потратили: $100
- Заработали: $300
- ACoS = 100/300 × 100% = 33%

Интерпретация:
ACoS < 30%   → Отлично! ✅
ACoS 30-40%  → Хорошо (улучшайте)
ACoS 40-50%  → Приемлемо (следите)
ACoS > 50%   → Слишком дорого (оптимизируйте)

ЦЕЛЬ: Снизить ACoS до 25-30%
```

#### **Где смотреть статистику:**

```
1. В Amazon Advertising Console:
   https://advertising.amazon.com

2. Нажать "Campaigns" (левое меню)

3. Видите таблицу со всеми метриками:
   - Impressions
   - Clicks
   - CTR
   - CPC (средняя ставка)
   - Spend
   - Orders (продажи)
   - Sales (дохода)
   - ACoS
   - ROAS

4. Кликнуть на кампанию для деталей
```

### **Шаг 7: Оптимизация (текущее)**

#### **НЕДЕЛЯ 1: Данные накапливаются**

```
Действия:
✓ Пусть работает (нужны данные)
✓ Наблюдайте, но не паникуйте
✓ Ожидайте 5-10 кликов минимум
✗ Не повышайте ставки слишком рано
✗ Не давайте бюджет > $10/день

Почему:
- Amazon нужны данные для оптимизации
- Алгоритм учится первые 7-14 дней
- Преждевременные изменения мешают обучению
```

#### **НЕДЕЛЯ 2: Анализ результатов**

Когда получите 20-30 кликов:

```
Если ACoS < 40% (хорошо):
✓ Немного повысьте бюджет (до $7-8/день)
✓ Слегка повысьте ставки (+10%)
✓ Добавьте ещё ключевых слов
✓ Продолжайте отслеживать

Если ACoS 40-60% (нужно улучшить):
⚠ Не повышайте бюджет
⚠ Следите за лучшими ключевыми словами
⚠ Может быть неправильное таргетирование
⚠ Попробуйте другие ключевые слова

Если ACoS > 60% (слишком дорого):
❌ Снизьте ставки на 20-30%
❌ Отключите худшие ключевые слова
❌ Проверьте таргетирование
❌ Рассмотрите создание новой кампании
```

#### **НЕДЕЛЯ 3+: Долгосрочная оптимизация**

```
Ежедневно:
□ Проверить расходы (не превышают ли бюджет)
□ Проверить новые ключевые слова (работают ли)

Еженедельно:
□ Анализировать ACoS по ключевым словам
□ Отключать неработающие ключевые слова
□ Повышать ставки на работающие
□ Проверять конкурентов

Ежемесячно:
□ Полный анализ кампании
□ Отчет о ROI
□ Планирование бюджета на следующий месяц
□ Тестирование новых ключевых слов
```

## ⚠️ Частые ошибки (избегайте!)

```
❌ ОШИБКА #1: Слишком высокая ставка
Неправильно: $2-3 за клик
Правильно: $0.50-1.00 за клик
Результат: потратите $300/месяц, а не $150

❌ ОШИБКА #2: Слишком много денег в начале
Неправильно: $50/день в первый день
Правильно: $5/день, потом увеличивайте
Результат: потеряете деньги на обучении алгоритма

❌ ОШИБКА #3: Неправильные ключевые слова
Неправильно: "книги", "ebook", "книга медицина"
Правильно: "antibiotics surgery", "infection control"
Результат: потратите на неправильный трафик

❌ ОШИБКА #4: Не отслеживаете ACoS
Неправильно: Тратите $300, зарабатываете $200 (150% ACoS!)
Правильно: Отслеживать еженедельно
Результат: можете потерять сотни долларов

❌ ОШИБКА #5: Отключите кампанию слишком рано
Неправильно: "Первые дни нет продаж - выключу"
Правильно: Дайте минимум 7-14 дней
Результат: никогда не узнаете результат

❌ ОШИБКА #6: Один плохой день = отключить
Неправильно: ACoS 60% в один день
Правильно: Смотреть среднее за неделю
Результат: неправильные решения
```
