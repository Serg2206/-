## 📊 НАСТРОЙКА АВТОРОМ НА AUTHOR CENTRAL

### Шаг 1: Связать книги
```
1. В Author Central → Books
2. Нажать "Add a new book"
3. Найти "Рациональное использование антибиотиков..."
4. Нажать "Link"
5. Подтвердить авторство (может потребоваться email)
```

### Шаг 2: Редактировать информацию о книге
```
1. В Author Central → Books → Ваша книга
2. Нажать "Edit book info"
3. Заполнить:
   - Description: [скопировать выше]
   - Key features: 
     ✓ Основано на американских протоколах CDC
     ✓ 15+ лет практического опыта автора
     ✓ Готовые рекомендации для внедрения
     ✓ Проверено в ведущих больницах США
   - Related books: [связанные книги, если есть]
4. Нажать "Save"
```

### Шаг 3: Добавить фото и видео
```
1. В Author Central → Profile
2. Загрузить фото (200×200 пикс)
3. Загрузить видео (если есть)
4. Нажать "Save"
```

### Шаг 4: Добавить социальные ссылки
```
1. В Author Central → Profile → Social Links
2. Добавить:
   - Website: https://ssvnauka.com
   - Twitter: @SergiyMD
   - LinkedIn: https://linkedin.com/in/ssvnauka
3. Нажать "Save"
```
