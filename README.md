## 🚀 Быстрый старт (3-7 дней)

### **День 1-2: eBook Creation** ⭐ ВЫСШИЙ ПРИОРИТЕТ
```
1. Войти в KDP Bookshelf → https://kdp.amazon.com
2. Выбрать "Create Kindle eBook"
3. Загрузить PDF/MOBI файл вашей книги
4. Установить цену: $9.99-11.99
5. Опубликовать
Время: 2-4 часа
```

### **День 2-3: Author Central** 
```
1. Зарегистрироваться → https://authorcentral.amazon.com
2. Подтвердить авторство своей книги
3. Загрузить биографию и фото
4. Добавить ссылки на сайт и соцсети
Время: 1-2 часа
```

### **День 3+: Amazon Ads Setup**
```
1. Дождаться публикации eBook (48-72 часа)
2. Войти в Amazon Advertising Console
3. Создать первую рекламную кампанию
4. Установить бюджет $5/день
5. Выбрать ключевые слова из рекомендаций
Время: 1-2 часа
```

### **День 4+: ACX (Опционально)**
```
1. Зарегистрироваться на ACX.com
2. Загрузить рукопись книги
3. Выбрать закрытую разработку или собственного нарратора
4. Ожидать создания 3-4 недели
Время: 30 мин на загрузку + ожидание
```
