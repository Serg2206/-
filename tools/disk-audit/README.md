# Аудит дисков Windows — `Invoke-DiskAudit.ps1`

Скрипт собирает полную картину по всем дискам компьютера: **здоровье (SMART), производительность,
занятое место, структуру папок, дубликаты, мусор и кэши**. Работает **только на чтение**:
ничего не удаляет и не меняет.

## Что проверяется

| Раздел | Что именно |
|---|---|
| Физические диски | модель, SSD/HDD/NVMe, здоровье, температура, износ SSD, часы работы, ошибки чтения/записи, SMART-прогноз отказа, разметка MBR/GPT |
| Тома | свободное место, файловая система, состояние, BitLocker |
| Оптимизация | TRIM для SSD, расписание дефрагментации/оптимизации, фрагментация HDD (`-AnalyzeFragmentation`) |
| Производительность | загрузка, очередь, задержки чтения/записи; бенчмарк winsat (`-Benchmark`) |
| Мусор и кэши | TEMP, кэш обновлений Windows, Windows.old, дампы, корзина, кэши браузеров, Telegram, npm/pip/NuGet, hiberfil.sys, pagefile.sys, точки восстановления |
| Docker / WSL | размер виртуальных дисков `.vhdx`, `docker system df`, список WSL-дистрибутивов |
| Структура | крупнейшие папки 1-3 уровня, типы файлов, файлы ≥ 200 МБ, данные, не менявшиеся 2+ лет |
| Порядок | вероятные дубликаты (≥ 50 МБ), «Загрузки», рабочий стол |

## Запуск (5 минут)

1. Скачайте `Invoke-DiskAudit.ps1` в папку «Загрузки»
   (на GitHub откройте файл → кнопка **Download raw file**).
2. Откройте **PowerShell от имени администратора**:
   `Win + X` → «Терминал (администратор)» / «Windows PowerShell (администратор)».
3. Выполните:

```powershell
cd $env:USERPROFILE\Downloads
Unblock-File .\Invoke-DiskAudit.ps1
powershell -ExecutionPolicy Bypass -File .\Invoke-DiskAudit.ps1
```

Из Git Bash:

```bash
cd ~/Downloads
powershell.exe -ExecutionPolicy Bypass -File Invoke-DiskAudit.ps1
```

Полное сканирование занимает от 3 до 30 минут: время зависит от количества файлов, на HDD дольше.
После завершения отчёт откроется в браузере сам.

### Варианты запуска

```powershell
# Быстро (1-2 мин): только здоровье, тома, системные папки и кэши — без полного обхода файлов
powershell -ExecutionPolicy Bypass -File .\Invoke-DiskAudit.ps1 -Quick

# Полный + замер скорости дисков + анализ фрагментации HDD
powershell -ExecutionPolicy Bypass -File .\Invoke-DiskAudit.ps1 -Benchmark -AnalyzeFragmentation

# Сканировать только диски C и D
powershell -ExecutionPolicy Bypass -File .\Invoke-DiskAudit.ps1 -Drives C,D
```

## Результат

Папка `Рабочий стол\DiskAudit_ГГГГ-ММ-ДД_ЧЧММ\`:

- `report.html` — наглядный отчёт; вверху таблица «Находки и рекомендации»:
  - **CRITICAL** — риск потери данных, действовать сразу;
  - **WARNING** — проблема производительности или надёжности;
  - **INFO** — место, которое можно безопасно освободить;
  - **ORDER** — наведение порядка.
- `summary.txt` — краткая сводка;
- `report.json` — полные данные.

**Дальше:** пришлите `summary.txt` (или `report.json`) в чат. По нему я составлю
конкретный план: что удалить, что перенести, что настроить, с готовыми командами.

> В отчёте есть пути к файлам и имена папок. Персональных данных пациентов скрипт не читает:
> содержимое файлов он открывает только для сравнения дубликатов, и хеш считается по трём
> фрагментам по 1 МБ.

## Рекомендуемая структура папок (схема «порядка»)

Принцип: **SSD — для системы, программ и текущей работы; HDD или внешний диск — для архива;
облако или второй внешний диск — для резервной копии.**

```
C:\  (SSD)            — только Windows и программы. Личные файлы здесь не хранятся.
D:\  (второй диск)
├── 01_MARIA_Клиника\          ← документы центра, договоры, прайсы, отчётность
│   ├── Пациенты\             ← (!) персональные данные — зашифровать (BitLocker)
│   └── Администрирование\
├── 02_Наука_Статьи\           ← SEO-статьи, публикации, рукописи книг (KDP)
├── 03_Сайт_ssvnauka\          ← исходники сайта, изображения, бэкапы БД
├── 04_YouTube\
│   ├── _Текущие_проекты\     ← монтаж сейчас (лучше на SSD)
│   ├── Исходники_RAW\        ← отснятый материал → в архив после публикации
│   └── Готовые_ролики\
├── 05_DevOps\                 ← Docker, cron, PowerShell-скрипты, git-репозитории
├── 06_Личное\
├── 90_Входящие\               ← вместо «Загрузок» и рабочего стола; разбирать раз в неделю
└── 99_Архив\                  ← закрытые проекты по годам: 2023\, 2024\, ...
```

Правила:
1. **Номера в начале имён** держат порядок сортировки папок.
2. **Не больше 3-4 уровней вложенности.**
3. **Имена файлов:** `ГГГГ-ММ-ДД_тема_версия.ext`, например `2026-09-29_миомэктомия_статья_v2.docx`.
4. **Раз в неделю** разбирайте `90_Входящие` и «Загрузки». **Раз в квартал** переносите закрытое в `99_Архив`.
5. **Резервное копирование по правилу 3-2-1:** 3 копии, на 2 разных носителях, 1 копия вне офиса
   (облако или внешний диск дома). Для медицинских данных это обязательно.

## Безопасность

- Скрипт ничего не удаляет. Все команды очистки в отчёте — это рекомендации,
  их выполняете вы сами после проверки.
- Не удаляйте вручную `C:\Windows\Installer`, `WinSxS`, `pagefile.sys`. Для них есть штатные средства:
  `cleanmgr`, «Параметры → Память», `DISM /Online /Cleanup-Image /StartComponentCleanup`.
- Перед удалением дубликатов откройте оба файла и убедитесь, что они одинаковые.
