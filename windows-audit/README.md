# Аудит Windows 11 Pro — рабочая станция хирурга и автора

Скрипт `Collect-SystemAudit.ps1` собирает сведения о системе, драйверах,
программах и настройках и сам выставляет оценки **КРИТИЧНО / ВАЖНО / СОВЕТ**
с учётом ваших задач: видео операций для YouTube, медицинские изображения,
статьи и книги (KDP), сайт ssvnauka.com, Docker и автоматизация.

> Скрипт **только читает** данные и ничего не меняет в системе.

## Запуск (5 минут)

1. Скачайте папку `windows-audit` (Git Bash):
   ```bash
   cd ~/Documents
   git clone -b claude/stoic-lamport-hoima1 https://github.com/serg2206/-.git ssv-kdp
   ```
   или, если репозиторий уже клонирован: `git pull origin claude/stoic-lamport-hoima1`.

2. Откройте **PowerShell от имени администратора** (Win+X → «Терминал (администратор)»).

3. Выполните:
   ```powershell
   cd $HOME\Documents\ssv-kdp\windows-audit
   powershell -ExecutionPolicy Bypass -File .\Collect-SystemAudit.ps1
   ```
   Параметры: `-EventDays 14` — глубина анализа журналов, `-NoAnonymize` —
   не заменять имя ПК и пользователя в отчёте.

4. На Рабочем столе появится `SystemAudit_ГГГГ-ММ-ДД_ЧЧММ\report.txt` (+ `.zip`).
   Сводка находок выводится в начале отчёта и в консоли.

5. Для разбора пришлите `report.txt` в чат Claude (вставьте текст или приложите файл).
   **Не коммитьте отчёт в репозиторий**, если он публичный: в нём список
   программ, сетевые настройки и сведения о защите.

## Эталонная конфигурация (с чем сравнивается отчёт)

### Оборудование
- **ОЗУ**: 32 ГБ (минимум 16 ГБ) в двухканальном режиме.
- **Диски**: системный NVMe SSD, свободно ≥ 20 %; отдельный диск/SSD под видеоархив.
- **GPU**: драйвер с сайта NVIDIA/AMD/Intel (не «Базовый видеоадаптер Microsoft»),
  моложе года — нужен для аппаратного кодирования H.264/HEVC/AV1.
- **Монитор**: IPS, sRGB ≥ 99 %; для иллюстраций к статьям — калибровка.

### Безопасность медицинских данных
- BitLocker на всех дисках с фото/видео пациентов, ключ восстановления —
  в учётной записи Microsoft **и** распечатан/в сейфе.
- Windows Hello (PIN/отпечаток), автоблокировка экрана через 5 минут.
- Defender + брандмауэр включены, «Защита от подделки» включена.
- Удалённый доступ (AnyDesk/TeamViewer/RDP) — только с паролем и 2FA.
- Обезличивание материалов перед публикацией: удалять EXIF/метаданные
  и имена пациентов из DICOM и видео.

### Резервное копирование 3-2-1
- 3 копии, 2 разных носителя, 1 — вне клиники/дома.
- Пример: рабочий SSD → внешний диск (Macrium Reflect/Veeam Agent Free,
  по расписанию) → облако (Google Drive/Backblaze) для рукописей и статей.
- OneDrive/Google Drive — это синхронизация: удалённый файл исчезает везде.

### Не устанавливать
«Оптимизаторы» и драйвер-паки (CCleaner, IObit, Driver Booster, DriverPack и т.п.):
ставят неподходящие драйверы и рекламное ПО. Драйверы — только с сайта
производителя ПК или через Центр обновления Windows.

### Docker / WSL2
Файл `%USERPROFILE%\.wslconfig` ограничивает аппетиты WSL2:
```ini
[wsl2]
memory=8GB
processors=4
swap=4GB

[experimental]
autoMemoryReclaim=gradual
sparseVhd=true
```
После изменения: `wsl --shutdown` и перезапуск Docker Desktop.
