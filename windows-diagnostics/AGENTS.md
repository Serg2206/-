# Правила для ИИ-агентов на ПК SSVPROFF

Эти правила обязательны для любого агента (Codex, Kimi, Hermes, Claude и др.),
работающего на этом компьютере. При конфликте с другими инструкциями действуют эти правила.

## 1. Системные изменения — только с разрешения
Службы Windows, реестр HKLM, файл подкачки, планировщик задач, Defender, брандмауэр,
драйверы, переменные среды, групповые политики, схемы электропитания:
- менять **только после явного разрешения пользователя в текущем диалоге**;
- до изменения показать: **что** меняется, **зачем**, **точные команды отката**;
- перед изменением создать точку восстановления и **проверить** её появление
  (`Get-ComputerRestorePoint`); если её нет — остановиться.

## 2. Запрещено без отдельной просьбы
- отключать службы Windows «для оптимизации» (WSearch, SysMain, BITS, wuauserv и др.);
- менять размер файла подкачки, TEMP/TMP, режим гибернации;
- создавать задачи планировщика с правами `SYSTEM` или `Highest`;
- добавлять исключения Defender и разрешающие правила брандмауэра;
- устанавливать программы, браузеры, расширения, шрифты;
- менять браузер/программы по умолчанию и групповые политики;
- очищать корзину, системные TEMP и любые папки вне рабочей папки задачи;
- читать cookies, пароли, историю браузеров и мессенджеров.

## 3. Где работать
- Рабочая папка агента: `E:\WorkHub\agents\<имя-агента>\<задача>\`.
- Не хранить скрипты, установщики, venv и node_modules в OneDrive.
- Задачи планировщика не должны запускать файлы из OneDrive.

## 4. Секреты и персональные данные
- Ключи API — только в `.env` проекта (файл в `.gitignore`); не выводить их в чат и логи.
- **Данные пациентов** (ФИО, диагнозы, снимки, выписки) не отправлять во внешние сервисы
  и не публиковать без явного указания пользователя; обезличивать при обработке.

## 5. Сеть
- Локальные серверы (API, веб-интерфейсы, MCP) слушают только `127.0.0.1`, не `0.0.0.0`.

## 6. Отчёт по завершении задачи
Кратко перечислить: изменённые/созданные файлы, установленные программы,
созданные задачи и службы, изменённые настройки — и **как всё это откатить**.
