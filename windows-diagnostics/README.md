# Диагностика медленного Windows 11

`Diagnose-SlowPC.ps1` — скрипт **только для чтения**: ничего не удаляет и не меняет, только собирает данные и формирует отчёт с выводами.

## Запуск

1. Скачайте `Diagnose-SlowPC.ps1`, например в `C:\Temp`.
2. Откройте **PowerShell от имени администратора** (Win+X → «Терминал (администратор)»).
3. Выполните:
   ```powershell
   cd C:\Temp
   powershell -ExecutionPolicy Bypass -File .\Diagnose-SlowPC.ps1
   ```
4. Около 1 минуты. Отчёт: `Рабочий стол\SlowPC_Report_<дата>.txt`. В его начале находится блок «ВЫВОДЫ».

## Что проверяется

| Блок | Что ищем |
|---|---|
| Система | аптайм, троттлинг CPU |
| Память | объём RAM, % занятости, файл подкачки |
| Диски | HDD или SSD, SMART, износ, температура, свободное место |
| Нагрузка | CPU / диск / свопинг за 10 секунд |
| Процессы | топ по RAM и CPU, суммарная память браузеров |
| Docker/WSL | vmmem, `.wslconfig`, размер VHDX |
| Автозагрузка | программы и сторонние задачи планировщика |
| Питание | схема электропитания |
| Антивирус | конфликт нескольких антивирусов, угрозы Defender |
| Временные файлы | %TEMP%, SoftwareDistribution, дампы |
| Журналы | ошибки диска, WHEA, Kernel-Power 41, время загрузки |
| Обновления/драйверы | давность обновлений, проблемные устройства |
