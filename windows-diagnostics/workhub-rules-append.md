
## Системная безопасность ПК (добавлено 2026-09-27)

Правила для любого агента (Codex, Hermes, Kimi и др.), работающего на ПК SSVPROFF:

- Службы Windows, реестр HKLM, файл подкачки, TEMP/TMP, планировщик задач, Defender,
  брандмауэр, драйверы, политики, электропитание — менять **только после явного разрешения**
  в текущем диалоге. До изменения показать: что меняется, зачем, точные команды отката.
- Перед системным изменением создать точку восстановления и **проверить** её появление
  (`Get-ComputerRestorePoint`); если точки нет — остановиться.
- Не отключать службы «для оптимизации» (WSearch, SysMain, BITS, wuauserv и др.).
- Не создавать задачи планировщика с правами `SYSTEM`/`Highest`; каждую созданную задачу
  указывать в отчёте вместе с командой удаления.
- Не добавлять исключения Defender и разрешающие правила брандмауэра.
- Не устанавливать программы, браузеры, шрифты и не менять программы по умолчанию без просьбы.
- Не очищать корзину и системные TEMP; удалять файлы только внутри рабочей папки задачи.
- Не читать cookies, пароли, историю браузеров и мессенджеров.
- Скрипты, venv и node_modules не хранить в OneDrive; задачи не должны запускать файлы из OneDrive.
- Локальные серверы (MCP, API, веб-интерфейсы) слушают только `127.0.0.1`.
- По завершении задачи — отчёт: что изменено/создано/установлено и как это откатить.
